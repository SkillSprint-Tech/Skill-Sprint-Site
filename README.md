# Skill Sprint Website

A modern, responsive marketing website for Skill Sprint built with **Vue 3**, **Vite**, and **Tailwind CSS**. This project features a dynamic, visually-driven layout with interactive elements and smooth animations.

## 🚀 Features

- **Modern UI**: Clean and contemporary design with high-quality visuals.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **Smooth Animations**: Built-in transitions and scroll effects for an enhanced user experience.
- **Easy to Customize**: Modular component architecture makes it simple to update content, colors, and styles.
- **Performance Optimized**: Built with Vite for fast cold starts and hot module replacement.
- **Tech Stack**:
  - **Vue 3**: Progressive JavaScript framework.
  - **Vite**: Next-generation frontend tooling.
  - **Tailwind CSS**: Utility-first CSS framework for rapid UI development.

## 🛠️ Setup

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

- [Node.js](https://nodejs.org/) (v16.0.0 or higher)
- [npm](https://www.npmjs.com/) (usually comes with Node.js)

### Installation

1.  **Clone the repository**
    ```bash
    git clone <repository-url>
    cd Skill-Sprint-Site
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

### Development

To start the development server, run:

```bash
npm run dev
```

This will start the Vite dev server, usually at `http://localhost:5173`.

### Build

To create a production build, run:

```bash
npm run build
```

This will create a `dist/` folder containing the optimized production code.

### Preview

To preview the production build locally, run:

```bash
npm run preview
```
